# 🐦 Flappy Bird

Um clone do clássico jogo Flappy Bird desenvolvido com HTML, CSS e JavaScript puro.

![Flappy Bird](https://img.shields.io/badge/Status-Em%20Desenvolvimento-yellow)
![License](https://img.shields.io/badge/License-MIT-blue)

## 🎮 [Jogar Agora](https://iagordgs.github.io/flappy-bird)

## 📋 Sobre o Projeto

Este projeto é uma recriação do famoso jogo Flappy Bird, desenvolvido como parte do curso "Web Moderno" da Udemy. O jogo foi construído utilizando HTML, CSS e JavaScript puro, sem frameworks ou bibliotecas externas.

## 🎯 Funcionalidades

- 🎮 Jogabilidade fiel ao original
- 🏆 Sistema de pontuação
- 🎨 Interface criada com HTML e CSS
- ⌨️ Controle simples (qualquer tecla)
- 💻 Otimizado para desktop

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura do jogo
- **CSS3** - Estilização e animações
- **JavaScript** - Lógica do jogo e interações

## 🎓 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei e aprendi:

- Manipulação do DOM
- Detecção de colisões
- Sistema de game loop
- Programação orientada a objetos em JavaScript
- Manipulação de eventos do teclado
- Criação de animações com CSS e JavaScript
- Posicionamento e movimento de elementos

## 🎮 Como Jogar

1. Acesse o [jogo online](https://iagordgs.github.io/flappy-bird)
2. Pressione **qualquer tecla** para fazer o pássaro voar
3. Desvie dos canos
4. Tente fazer a maior pontuação possível!

> ⚠️ **Nota:** No momento, o jogo está disponível apenas para desktop.

## 💻 Executar Localmente
```bash
# Clone o repositório
git clone https://github.com/iagordgs/flappy-bird.git

# Entre no diretório
cd flappy-bird

# Abra o arquivo index.html no navegador
# Ou use um servidor local como Live Server (VS Code)
```
